§ Computational methods — Monitoring sequences and treatment feedback
Natural-cycle transfer monitoring supplies a classification example. XGBoost predicts relative ovulation classes from hormones and ultrasound, using several derived observations per cycle. A later retrospective comparison examines pregnancy outcomes under physician timing and model-consistent timing. The two analyses address monitoring classification and timing-associated outcomes, with the cycle as the shared biological unit [@EC069].
Adjudicated scope: AI adjudication. Human true natural-cycle FET timing prediction with learned XGBoost and empirical evaluation directly meets IVF monitoring/transfer scope. The later pregnancy comparison is retrospective agreement with physician decisions, not model-directed treatment. Five relative ovulation classes and multiple derived instances per cycle must be distinguished from exact cycle-level timing accuracy.
Method summary: Three non-overlapping datasets were used. A 500-cycle expert-labeled dataset was split by patient into training, validation, and test groups; a selected 101-cycle dataset with follicular rupture and an LH surge provided a second accuracy test; and 515 later NC-FET cycles were classified by whether physician-scheduled transfer matched the model's ovulation-plus-five-day recommendation. XGBoost used 20 sequentially selected features from hormones, ultrasound, and baseline variables. Logistic regression adjusted the clinical-pregnancy comparison for age, BMI, endometrial thickness, embryo quality, and prior retrievals.
