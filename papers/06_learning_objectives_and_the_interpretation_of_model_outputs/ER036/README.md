> **§ Learning objectives and the interpretation of model outputs** : Probability estimation, discrimination and calibration
> ==Outcome harmonization links each definition to its denominator and purpose. The Vienna laboratory consensus defines process indicators with reference populations, including injected MII oocytes for normal ICSI fertilization. COMMIT establishes a minimum outcome set and companion reporting definitions for infertility trials, including randomized-participant denominators where appropriate. Its live-birth threshold differs from the international glossary threshold, so extraction retains the definition used in each study. Twins contribute two newborns to a newborn count and one event to a delivery count [@ER033,ER034,ER035,ER030]. The male-infertility core outcome initiative extends outcome selection to partner and offspring health and refers semen definitions to the WHO manual. It provides a framework for organizing laboratory measurements and subsequent reproductive outcomes within the same evaluation program [@ER036].==
